// capabilities

Everything you need. Nothing you don't.

Deep fingerprinting
Matches HTTP headers, HTML source, JavaScript globals, DOM structure and CSS variables against 1,500+ technology patterns — with corroborated framework detection, so no false React/Svelte hits.
Security header audit
Pass/fail scoring for CSP, HSTS, X-Frame-Options, Referrer-Policy, Permissions-Policy, COOP/COEP/CORP and more — present values shown in full.
API & WebSocket detection
Finds the real endpoints a site calls — REST, GraphQL, JSON-RPC, SOAP, gRPC and WebSocket — with concrete URLs pulled from captured requests and source.
Spider
Crawl a site into a page map — seeded from its sitemap and robots.txt, following links where needed. Same-site, polite, with start/pause/stop and copy-all.
HTTP Repeater
Craft and replay raw HTTP requests with full header control — raw editor or visual wizard, pre-populated from the scan, with a fullscreen response viewer.
Live network & JS console
Watch every request the page makes in real time, filterable by type — and run JavaScript directly in the page context, DevTools-style.
Intel & Recon
WHOIS/RDAP, DNS records, ASN, TLS certificate details, social links, robots.txt, security.txt and sitemaps — all gathered in one scan.
Full HTML reports
Export a complete, shareable HTML report covering techs, headers, TLS, cookies, APIs and network. Open in Chrome, print to PDF.
Fully on-device
No backend, no account, no telemetry. Scans run entirely in the embedded browser on your phone — long-press any value to copy it.
// how it works

Three steps.

01
Enter any URL
Paste or type any website — no https:// required. Or share a link straight from Chrome; Ecliptic appears in the share sheet.
02
Scan
The embedded Chromium engine loads the page, injects probes, intercepts network requests and collects signals — exactly like a real browser visit.
03
Explore & export
Browse techs, audit security headers, spider the site, inspect requests, run console commands, and export a full report.
