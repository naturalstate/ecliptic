// capabilities

Everything you need. Nothing you don't.

🔍
Deep fingerprinting
Matches HTTP headers, HTML source, JavaScript globals, DOM structure, and cookies against 1,500+ technology patterns.
🛡
Security headers
Instant pass/fail audit for CSP, HSTS, X-Frame-Options, Referrer-Policy, Permissions-Policy, and more.
🔄
HTTP Repeater
Craft and replay raw HTTP requests with full header control. Raw editor or visual wizard — both modes included.
📡
Live network capture
Watch every request the page makes in real time. Filter by type — scripts, XHR, images, fonts, media.
⌨️
JS console
Run JavaScript directly in the page context. Same as Firefox DevTools — access window, localStorage, fetch, and more.
📋
Full reports
Export a complete HTML report covering techs, headers, TLS, cookies, DNS, APIs, and network. Open in Chrome, print to PDF.
🔎
Intel & Recon
WHOIS, DNS records, ASN info, TLS certificate details, robots.txt, sitemap, and security.txt — all in one scan.
🔐
Fully on-device
No backend. No account. No telemetry. Scans run entirely in the embedded browser on your phone.
// how it works

Three steps.

01
Enter any URL
Paste or type any website URL. Or share a link directly from Chrome — Ecliptic appears in the share sheet.
02
Scan
The embedded Chromium engine loads the page, injects probes, intercepts network requests, and collects signals — same as a real browser visit.
03
Explore results
Browse detected technologies, audit security headers, inspect raw requests and responses, run console commands, and export a full report.
