// capabilities

A recon suite in your pocket.

Nine tools, one scan, from deep fingerprinting to adversarial security analysis. Everything runs in an embedded Chromium engine on your device.

Deep fingerprinting
Matches HTTP headers, HTML source, JavaScript globals, DOM structure and CSS variables against 1,500+ technology patterns, with corroborated framework detection. Brand icons for every match.
Security-depth analysis
Beyond pass/fail, it flags clickjacking exposure, weak CSP (unsafe-inline, wildcards), CORS misconfig, missing SRI on third-party scripts, HSTS gaps, mixed content and info disclosure, each with the offending value.
new
Subdomain intel
Maps a domain's attack surface from certificate-transparency logs and the live project, passively, as part of every scan. Active enumeration against bundled wordlists is on the roadmap.
new
Build-origin estimate
Guesses whether a site was AI-built. Names the platform on a hard marker (Lovable, v0, bolt.new, Replit, Framer), and reads code-comment style for an LLM-authorship band. Evidence-first, never claims which model, no vanity score.
new
DNS & email security
Checks SPF, DMARC, DKIM, DNSSEC and CAA, the records that decide whether a domain can be spoofed. Clear pass/fail with the raw record values, no vanity grade.
new
Trust signals
Keyless reputation context: domain age from registration data, DNSSEC, enforced HTTPS, email auth, and registered look-alike / typosquat domains that could impersonate the target.
new
Hosting & IP intel
Resolves the server IP, ASN and network, and reverse-IP neighbors sharing the host, flagging dedicated vs shared hosting, with WHOIS/RDAP and TLS certificate detail alongside.
new
Spider
Crawl a site into a page map, seeded from its sitemap and robots.txt, following links where needed. Same-site, polite, with start/pause/stop and copy-all.
HTTP Repeater
Craft and replay raw HTTP requests with full header control, raw editor or visual wizard, pre-populated from the scan, with a fullscreen response viewer.
Live network & JS console
Watch every request the page makes in real time, filterable by type, detect REST, GraphQL, WebSocket and gRPC endpoints, and run JavaScript in the page context, DevTools-style.
Full HTML reports
Export a complete, shareable report, techs, security analysis, headers, TLS, cookies, subdomains, DNS/email security, trust signals, hosting and network. Open in Chrome, print to PDF.
Fully on-device
No backend, no account, no telemetry. Scans run entirely in the embedded browser on your phone, long-press any value to copy it.
Shareable & scriptable
Share a URL straight from Chrome into Ecliptic via the share sheet. Every result copies clean; reports are plain HTML you can diff, archive or hand to a client.

// how it works

Three steps.

01
Enter any URL
Paste or type any website, or share a link straight from Chrome. Ecliptic appears in the share sheet.
02
Scan
The embedded Chromium engine loads the page, injects probes, intercepts network requests and runs recon lookups in parallel, exactly like a real browser visit, plus DNS and certificate intel.
03
Explore & export
Browse techs, audit security, map subdomains and hosting, spider the site, replay requests, and export a full HTML report.
